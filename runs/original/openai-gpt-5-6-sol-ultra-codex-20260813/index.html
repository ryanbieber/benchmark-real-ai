BUILD IT YOURSELF

From prices to a forecast in four transparent steps.

This is an explanatory baseline, not a trading system. The useful habit is separating a central path from the uncertainty around it.

  1. 01
    Transform prices

    Compute daily log returns so changes are comparable through time.

    rₜ = ln(Pₜ / Pₜ₋₁)
  2. 02
    Estimate a signal

    Blend capped long-run drift, local trend and multi-period momentum.

    μ = Σ weightᵢ × signalᵢ
  3. 03
    Project the path

    Compound the daily signal across the chosen trading-day horizon.

    P̂ₜ₊ₕ = Pₜ × exp(μh)
  4. 04
    Add uncertainty

    Scale observed volatility by √h and test forecasts from historical origins.

    band = exp(± zσ√h)
