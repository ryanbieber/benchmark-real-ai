01 / The premise

A practical benchmark for the models we actually use.

New models arrive with sweeping claims. Benchmarks compress them into a number. But the real question is simpler: what happens when you ask the model to make something useful?

This project keeps the task constant and exposes the conditions around it. The model, reasoning setting, and harness all matter—so all three stay visible.

Same goal

02 / The protocol

What each run records

This is a showcase, not a universal leaderboard. Scores help you inspect the work; they do not crown a winner.

MODEL

Exact identity

Provider, model ID, version, and run date.

EFFORT

Reasoning setting

Native value plus a disclosed normalized band.

HARNESS

Agent environment

Name, version, interface, configuration, and tools.

EVIDENCE

Validation trail

Commands, outcomes, source classification, and repairs.
